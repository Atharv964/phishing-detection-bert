About PhishGuard

PhishGuard is an AI-powered phishing detection system developed to identify malicious URLs and protect users from phishing attacks. The system analyzes URL patterns using advanced machine learning and natural language processing techniques.

Technologies Used

Python
Flask
BERT Transformer
Machine Learning
Random Forest
HTML / CSS / JavaScript

Project Goal

The goal of this project is to build an intelligent system that detects phishing websites by analyzing URL structures and semantic patterns using artificial intelligence.
